# 주제

기존 계약·계획 문서의 반복이라면 새 노트를 만들지 않는다. 구현 전 결정은 예상 영향과 검증 계획을 실제 관찰·검증 결과와 구분해 적는다.

- **상태:** 조사 중 / 해결 / 보류 / 폐기
- **발견일:** YYYY-MM-DD
- **관련 기능:**

## 배경

- 무엇을 하려 했는가?
- 처음에는 어떻게 동작할 것으로 예상했는가?

## 관찰

- 실제로 무엇이 일어났는가?
- 오류, 로그, 쿼리, 테스트 결과 등 확인 가능한 근거는 무엇인가?

## 고민한 선택지

1. 선택지와 장점·단점
2. 선택지와 장점·단점

## 결정과 수정

- 무엇을 선택했는가?
- 왜 선택했는가?
- 어떤 범위를 변경했는가?

## 검증

- 어떻게 다시 확인했는가?
- 결과는 무엇인가?

## 남은 내용

- 해결되지 않은 조건이나 위험은 무엇인가?
- 다음에 다시 확인할 것은 무엇인가?
